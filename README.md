## 📌 Tentang Repositori Ini

Repositori ini berfungsi sebagai gerbang utama (*landing redirect*) menuju aplikasi web portofolio interaktif yang memuat dokumentasi analisis data, publikasi ilmiah, serta sertifikasi kompetensi profesional.

### ✨ Fitur Utama Web Portofolio
* **💻 Portofolio Syntax (R, Stata, SPSS):** Katalog skrip ekonometrika dan pengolahan data survei lengkap dengan filter software, pencarian metode, serta proteksi kata sandi untuk skrip bersifat *private*.
* **📚 Publikasi Ilmiah:** Daftar artikel jurnal dan prosiding beserta visualisasi grafik jumlah publikasi per tahun dan filter tahun interaktif.
* **🏆 Sertifikat & Kompetensi:** Arsip kredensial pelatihan dan keahlian dengan grafik tren sertifikasi tahunan.

---

## 🛠️ Arsitektur Sistem

Aplikasi portofolio ini dibangun menggunakan pendekatan *serverless* berbasis ekosistem Google dan GitHub:
* **Frontend & Routing:** GitHub Pages (`index.html`) & Google Apps Script HTML Service
* **Backend API:** Google Apps Script (`Code.gs`)
* **Database Dinamis:** Google Sheets (mengelola konfigurasi profil, tautan akademik, katalog syntax, publikasi ilmiah, dan sertifikat secara *real-time*)
